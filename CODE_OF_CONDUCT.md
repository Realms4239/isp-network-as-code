# Code of Conduct

## Our standard

Contributors must create a professional, welcoming, and technically rigorous environment. Be respectful, assume good intent, and critique ideas and code rather than people.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized language, doxxing, credential sharing, and deliberate disruption of lab or CI infrastructure are not tolerated.

## Reporting

Report concerns privately to the maintainers. Reports will be reviewed confidentially and handled as appropriate.

## Scope

This policy applies to repository discussions, issues, pull requests, CI artifacts, and any space where project contributors communicate.
